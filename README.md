# pancoh.github.io

Arquivo de projetos publicado em [ramson.com.br](https://ramson.com.br).

O site usa poucos arquivos:

- `index.html`: conteúdo e cards dos projetos;
- `estilo.css`: apresentação visual e responsividade;
- `assets/projetos/`: miniaturas dos projetos públicos (capturas de tela em WebP, 960 por 600).

Para incluir um projeto, copie um card existente em `index.html` (um `<a class="card">` para projeto público ou um `<article class="card internal">` para projeto interno) e ajuste textos, categoria e contagens dos filtros.

Para alterar o catálogo, edite esses arquivos e envie as mudanças para a branch `main`. O GitHub Pages publica a atualização automaticamente.

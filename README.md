# pancoh.github.io

Portfólio pessoal publicado em [ramson.com.br](https://ramson.com.br).

O site usa apenas dois arquivos:

- `index.html`: conteúdo e lista de projetos;
- `editorial.css`: apresentação visual e responsividade.

Para alterar o portfólio, edite esses arquivos e envie as mudanças para a branch `main`. O GitHub Pages publica a atualização automaticamente.
